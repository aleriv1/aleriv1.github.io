- Во второй части для проверки доступности сети также использовал запрос fetch на https://google.com/favicon.ico. Код вроде был правильный -- можно посмотреть в истории коммитов -- но в результате всегда отображалось offline. Использовал подсказку из комментов на платформе -- react-detect-offline
- В коде -- В app.jsx -- закоментированно Promise.reject для теста ошибки (просто, не offline), и условия для постоянного отображения лоадера, если надо.
- Также в app.jsx небольшой таймаут перед обновлением state, чтобы точно показать лоадер.
