Оптимальная сортировка не равнялась самой дешёвой

формулу использовал:

Общий вес билета=Цена (руб)+k×Время в пути (часы)

это вроде распространный подход в транспортных сервисах, когда надо быстро отсортировать

Просто k было небольшой, 15 (при загрузке дополнительных билетов фильтр менялся); увеличил до 500, нагляднее стало

В файле index.js в store -- там actions и соедение редьюсеров -- закомментированные строки для добавления redux devtools; почтитав комментарии на платформе, сделал неактивными, чтобы не возникало вопросов

Логика для оптимальной сортировки -- тоже у коллеги с платформы подсмотрел; но она вроде, по данным Сети, имеет смысл: цена билета А + время полета \* 15.
